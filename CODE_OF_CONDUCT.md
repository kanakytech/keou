# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind. We build
tools for people across the Pacific and beyond — the standard here is the one
you would hold in someone else's house.

Reports: contact@kanaky.xyz. All reports are read by a human and handled
confidentially.
